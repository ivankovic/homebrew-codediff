# homebrew-omnidiff

The Homebrew tap for [omnidiff](https://github.com/ivankovic/omnidiff):

    brew install ivankovic/omnidiff/omnidiff

`Formula/omnidiff.rb` is written by the omnidiff release workflow from each release's
checksums; do not edit it here. The template lives in the omnidiff repository under
`packaging/homebrew/`.

This tap was `ivankovic/codediff` up to v0.1.1. `formula_renames.json` lets an existing
`codediff` install move to `omnidiff` on the next `brew upgrade`.
