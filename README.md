# homebrew-codediff

The Homebrew tap for [codediff](https://github.com/ivankovic/codediff):

    brew install ivankovic/codediff/codediff

`Formula/codediff.rb` is written by the codediff release workflow from each release's
checksums; do not edit it here. The template lives in the codediff repository under
`packaging/homebrew/`.
